# Imolia Desktop Customizer 1.2.0

Two new widgets, mail you can read right in the widget, a much faster and more reliable desktop, and a complete documentation overhaul.

## New

**Gmail Inbox widget** - all your Gmail accounts at a glance.
- The unread counter of every account in one widget, checked every few minutes, with the newest unread mails listed per account.
- **Read a mail inside the widget** - no browser window pops up. Formatted mails (newsletters) are shown in a simplified, safe way: images are never loaded and scripts, frames and forms are removed. Links show where they really go.
- Mark mail as read or move it to the trash from the widget; trashed mail stays in Gmail's Trash for 30 days.
- Give each account a **display name** (for example "Private") so no e-mail address is visible on your screen.
- Choose your own **notification sound** (any Windows sound or your own `.wav`) and silence everything with the **do-not-disturb** bell.
- Signs in with a Google **app password** per account. The passwords are stored encrypted (Windows DPAPI).

**System Overview widget** - the Windows Task Manager, but all graphs at once: CPU, memory, GPU, GPU memory, network and disk, with GPU temperature and power draw (NVIDIA only).

## Better

- **No more freezes:** the Google Calendar widget downloads in the background; the LLM Chat widget no longer blocks while it waits for an answer.
- **Dragging is lighter:** widgets no longer rewrite their settings file for every mouse movement.
- **The log can no longer grow forever:** it rotates at 2 MB.
- **Safer:** the LLM Chat widget now stores your OpenAI key encrypted and never writes it to a log.
- **LLM Chat actually works** with the OpenAI library that ships with the program.
- Fixes: the *Save* button in the Pomodoro and System Monitor settings no longer crashes; the Clock widget's colors and fonts take effect and it no longer overflows when resized; the To-Do widget keeps its colors; opening *Widgets Beheren* no longer triggers an endless loop.
- **Documentation:** a rewritten User Guide, a Troubleshooting guide, an Architecture overview, READMEs and screenshots for every widget, and a security policy.

## Updating from an earlier version

1. Quit the program (**Exit** in the tray menu) and replace the program folder with this one. Your widgets, settings and data are stored elsewhere and are kept.
2. The two **new widgets appear automatically** the next time you start the program.
3. **Existing widget files are never overwritten.** To get the fixes in the other widgets, copy the `.py` files from the `_internal\widgets` folder of this download over the ones in `Documents\Imolia Desktop Customizer Widgets` (your settings are in separate `_config.json` files and are kept), or delete an old `.py` file there and restart - the program copies the new one back.
4. The old, large `app.log` is moved aside to `app.log.1` the first time; you can delete it.

## Good to know

- **Windows** (developed and tested on Windows 11); nothing else to install.
- Gmail needs 2-Step Verification and an app password ([how](https://github.com/imoliamedia/Imolia-Desktop-Customization-Tool/blob/main/widgets/gmail_inbox_widget/README.md#setting-up-an-account)).
- GPU panels in System Overview need an NVIDIA card; CPU temperature needs LibreHardwareMonitor to be running.
- LLM Chat needs your own OpenAI API key and sends every question on its own (the model has no memory of earlier questions).
- Packages with compiled parts cannot be installed from the settings window in this build; see the Widget Development Guide, "Handling Dependencies".
